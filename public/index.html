⠿▾ Color Palette

Click a color to turn it on or off for this tool. Active colors are what shows up in the right-click menu and Edit Grid — turning one off doesn't erase cells already using it, it just hides its controls until you turn it back on.

Click a cell (or shift/ctrl-click for more than one), pick or type a hex value, and Apply Hex. Leave the name blank for a one-off color just on this cell — give it a name and it also joins the palette above as an active color, showing up in the right-click menu and Fine-Tune from then on.

⠿▾ Recent Cards

Remembers the last several cards you've saved, in this browser only — not across devices or browsers. In Chrome/Edge, "Open" reopens the actual file directly (it'll ask permission first). In Safari/Firefox, or if a file was moved/renamed/deleted since, entries are a log only — use Import to reopen them by hand.

⠿▾ Compare Cards

Loads a second saved card and lists what's different, without touching what's currently on screen — useful if two people edited separate copies and you need to combine their changes by hand.
